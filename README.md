# SIMFONI ITK 2026 — Slide Workshop

Live: https://myst-tech.com/simfoni-itk-2026/

Presentasi "Integrasi AI untuk Kebijakan dan Keputusan Strategis yang Berdampak" (Slidev).

## Jalankan lokal
```bash
npm install        # sekali saja
npm run dev        # buka http://localhost:3030
```
- Mode presenter (catatan pembicara + timer): http://localhost:3030/presenter
- Ekspor PDF: `npm run export` (butuh `npx playwright install chromium` sekali)

## Struktur
- `slides.md` — semua slide (pemisah `---`, catatan pembicara di `<!-- -->`)
- `styles/index.css` — warna & huruf
- Naskah lengkap + lembar kerja: `~/Projects/sepingganbaru-rt/materi-simfoni-2026.md`
